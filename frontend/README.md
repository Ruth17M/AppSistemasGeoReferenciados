# AcopioMap · Frontend

Aplicación React creada con la plantilla oficial de **Vite** (`npm create vite@latest -- --template react`).

```bash
cp .env.example .env    # ajusta VITE_API_URL
npm install
npm run dev             # http://localhost:5173
npm run build           # genera dist/ para producción
```

Consulta el `README.md` de la raíz del repositorio para la documentación completa.
